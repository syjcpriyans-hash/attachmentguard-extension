ATTACHMENTGUARD v0.4 — UPDATE STEPS

1. Extract this ZIP.
2. Open your EXISTING GitHub repository:
   attachmentguard-extension
3. Replace the repository files with everything from this ZIP.
4. Commit to main.
5. Open GitHub → Actions.
6. Wait for "Build AttachmentGuard Chrome Extension" to turn green.
7. Open the successful run.
8. Download artifact:
   AttachmentGuard-Chrome-Extension
9. Extract that artifact ZIP.
10. Open:
    chrome://extensions
11. Remove the old AttachmentGuard development extension.
12. Click "Load unpacked".
13. Select the extracted artifact folder containing manifest.json.
14. Confirm AttachmentGuard version is 0.4.0.

TEST

15. Open a PDF normally in Chrome.
16. It should NOT show the old AttachmentGuard website/editor screen.
17. It should look like a normal dark PDF viewer:
    - thumbnails on left
    - PDF pages in center
    - compact toolbar at top
18. Click the pencil icon.
19. Hover PDF text. A subtle blue outline should appear.
20. Click the text.
21. Type the correction directly on the PDF.
22. Press Enter.
23. Wait for "Saved ✓ — verified PDF edit".
24. Click Save.
25. Chrome opens the Save dialog for the corrected PDF.

You can also click the AttachmentGuard extension toolbar icon while a PDF is open to toggle inline edit mode.

NOTE:
"Save" saves the corrected PDF to the user's computer.
A universal extension cannot overwrite the source file on every remote website because each website controls its own server. Site-specific save-back adapters can be added later without changing PDFium.
