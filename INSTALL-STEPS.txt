ATTACHMENTGUARD v0.3 — UPDATE + TEST

1. Extract the v0.3 source ZIP.
2. Open your EXISTING GitHub repository: attachmentguard-extension.
3. Upload/replace the files from this ZIP in the same repository.
   Do not create a new repository and do not create a new Vercel project.
4. Commit to main.
5. Open GitHub → Actions.
6. Wait for "Build AttachmentGuard Chrome Extension" to turn green.
7. Open the successful run → Artifacts → download AttachmentGuard-Chrome-Extension.
8. Extract the artifact ONCE. The extracted folder should directly contain manifest.json, editor.html, sidepanel.html, background.js and assets/.
9. Open chrome://extensions.
10. Remove the old AttachmentGuard development extension OR click Reload after replacing its folder. For the cleanest test, remove the old one and use Load unpacked on the newly extracted artifact folder.
11. Confirm AttachmentGuard shows version 0.3.0.

FIRST PDF TEST

12. Open this direct PDF in a new tab:
    https://www.w3.org/WAI/ER/tests/xhtml/testfiles/resources/pdf/dummy.pdf
13. IMPORTANT: do not click the extension first.
14. Because AttachmentGuard is now registered as Chrome's PDF handler, the PDF should open directly inside AttachmentGuard's editor while the original PDF URL remains in Chrome's address bar.
15. Confirm ENGINE: PASS ✅.
16. Confirm the PDF is rendered.
17. Click/edit text if the PDF contains editable text objects.
18. Download the corrected attachment.

PDF HANDLER TOGGLE

19. On a normal webpage, click the AttachmentGuard toolbar icon.
20. The side panel shows "Chrome PDF handling".
21. You can switch between AttachmentGuard and Chrome's normal PDF viewer without uninstalling the extension.

IF A PDF CANNOT BE RENDERED

AttachmentGuard calls Chrome's native PDF fallback. This is intentional professional behavior.
