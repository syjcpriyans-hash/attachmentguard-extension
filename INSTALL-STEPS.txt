ATTACHMENTGUARD v0.5 — UPDATE STEPS

1. Extract this ZIP.
2. Open your EXISTING GitHub repository:
   attachmentguard-extension
3. Replace repository files with everything from this ZIP.
4. Commit to main.
5. Open GitHub → Actions.
6. Wait for Build AttachmentGuard Chrome Extension to turn green.
7. Open the successful run.
8. Download artifact:
   AttachmentGuard-Chrome-Extension
9. Extract the artifact.
10. Open chrome://extensions
11. Remove the old AttachmentGuard extension OR click Remove, then Load unpacked.
12. Select the new artifact folder containing manifest.json.
13. Confirm version is 0.5.0.

TEST 1 — ENTER

14. Open your invoice PDF.
15. Click the pencil icon.
16. Click a text object.
17. Type the correction.
18. Press Enter ONE TIME.
19. Expected:
      Saved ✓ — verified PDF edit
    If the exact font is genuinely needed, the typed text must remain preserved while the font dialog is shown.
    Canceling that dialog must return you to the same typed edit; you should not have to type it again.

You can also click the blue ✓ beside the inline field instead of pressing Enter.

TEST 2 — FILE NAME

20. Click the PDF filename in the top-left toolbar.
21. Replace it, for example:
      Invoice 34413 - Corrected.pdf
22. Press Enter.
23. Click Save.
24. Chrome Save As should already contain:
      Invoice 34413 - Corrected.pdf

Shortcut:
Ctrl+S = Save corrected PDF with the current toolbar filename.
