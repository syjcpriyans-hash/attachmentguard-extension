# AttachmentGuard Text Kernel v1 — Acceptance Matrix

Do not add new PDF features until the supported rows below behave correctly.

## Selection kernel
- [ ] Full word stored in one PDF text object
- [ ] Full word fragmented across 2 objects
- [ ] Full word fragmented across 5+ objects
- [ ] Word separated by an explicit PDF space
- [ ] Word separation inferred from geometry when PDF has no generated space
- [ ] Punctuation remains attached correctly
- [ ] Number such as 34413 is selected as one unit
- [ ] Postal code fragments are selected as complete individual words
- [ ] Columns on the same baseline do not merge
- [ ] Different rows do not merge
- [ ] Mixed-style word is visibly blocked, not destructively edited
- [ ] Rotated/unmapped/generated-only word is visibly blocked

## Rewrite kernel
- [ ] Partial-object word replacement preserves unselected prefix/suffix text exactly
- [ ] Same-length partial-object replacement passes pixel collateral guard
- [ ] Shorter partial-object replacement either passes all verification or blocks cleanly
- [ ] Longer partial-object replacement either passes all verification or blocks cleanly
- [ ] Fragmented word across complete secondary objects is rewritten atomically
- [ ] Fragmented word crossing a secondary object with unrelated text is blocked
- [ ] Exact-font resolver is invoked only when required
- [ ] User's typed correction survives a font-resolution prompt
- [ ] Undo restores the last good PDF

## Verification
- [ ] Output PDF saves and reopens
- [ ] Replacement Unicode matches exactly
- [ ] No Unicode mapping errors
- [ ] Font identity/style/size preserved
- [ ] Fill/stroke/render mode preserved
- [ ] Object transform preserved
- [ ] No neighboring-object collision
- [ ] Pixel guard detects collateral changes outside edited region
- [ ] Failed verification never replaces the last-good PDF

## Sources
Test at minimum with PDFs generated by:
- browser print-to-PDF
- Microsoft Office export
- accounting/invoice software
- logistics/carrier software
- Adobe/Acrobat
- scanned PDF (must be classified as non-existing-text-editable, not fail strangely)
